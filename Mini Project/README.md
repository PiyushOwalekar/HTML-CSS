# MindCare - Online Therapy Platform

A modern, premium multi-page website inspired by BetterHelp, offering online therapy services for individuals, couples, and teens.

## 🌟 Features

### Pages
- **Home** (`index.html`) - Hero section, therapy options, how it works, comparison table, testimonials
- **About** (`about.html`) - Mission, values, story, and leadership team
- **Services** (`services.html`) - Detailed therapy services, formats, and pricing
- **FAQ** (`faq.html`) - Frequently asked questions with interactive accordion
- **Contact** (`contact.html`) - Contact options, form, and crisis support

### Design Highlights
- **Premium Aesthetics**: Modern gradients, smooth animations, and glassmorphism effects
- **Rich Color Palette**: Harmonious green-based palette with coral and gold accents
- **Typography**: Google Fonts (Inter & Outfit) for clean, professional look
- **Responsive**: Mobile-friendly design with breakpoints
- **Interactive**: Animated counters, FAQ accordions, form validation, scroll effects

### Interactive Elements
- ✨ Smooth scroll animations
- 🎯 FAQ accordion functionality with category filtering  
- 📊 Animated statistics counters
- 🎨 Hover effects and micro-animations
- 📝 Working contact form with validation
- 🌊 Parallax background effects
- 💫 Button ripple effects

## 🚀 How to Use

1. Open `index.html` in your browser to view the homepage
2. Navigate between pages using the header menu
3. All pages are fully functional and interactive

## 💡 Key Technologies

- **HTML5** - Semantic markup
- **CSS3** - Modern styling with custom properties, gradients, animations
- **Vanilla JavaScript** - No frameworks, pure JS for interactivity
- **SEO Optimized** - Proper meta tags, headings, and semantic structure

## 🎯 Design Philosophy

Following modern web design best practices:
- **Premium First Impression** - Vibrant colors, dynamic animations
- **User Engagement** - Interactive elements and micro-animations
- **Accessibility** - Semantic HTML, proper contrast, keyboard navigation
- **Performance** - Optimized assets, efficient animations

## 📱 Responsive Breakpoints

- Desktop: 1200px and above
- Tablet: 768px - 1199px
- Mobile: Below 768px

## 🔧 Customization

To customize the website:
1. Update colors in CSS variables (`:root` section in `styles.css`)
2. Modify content directly in HTML files
3. Adjust animations in `script.js`
